## Items

- **C-1 script-wave.js sampling.** `blindRate = Math.max(1, Math.floor(Number(args.blindRate || 1)))`; `always = new Set(args.alwaysSample || [])`; `sampleOf(ids)` = sorted unique ids kept when `always.has(id) || i % blindRate === 0` (index-based; the workflow runtime has no Math.random / Date). Stage 2 passes only the sampled ids to `scenarioPrompt` and returns `{ b, a, s, sampled }`; the result row gains `blindRate` and `blindSampling: [{ oracleId, blindSampled }]` for every verified id. A batch with no sampled id skips the scenario agent (`s: null`, already tolerated by the judge stage and the mapper). Log one line per batch: `<batch>: blind scenarios for K/N`.
- **C-1b script-wave.js resume.** `args.resume = { results: [<prior batch rows>], reauthor: [<batch paths>] }`: a batch whose path has a prior row and is not in `reauthor` skips the author agent and reuses the row's `written / verified / blocked / needs / parserRuleSuggestions / toolProblems` as the author result; `args.rerun` (integer, default 0) is folded into every prompt string (e.g. `Run ${rerun}.` at the end) so a cached refusal never replays. Judge prompts must cope with `s === null` (they already do). Keep the file's one-object-per-line style; keep the inner-backtick rule (no backticks inside the template literals — that broke the parser once).
- **C-1c blindness leak.** In the blind-scenario prompt forbid `npx tsx -e` / CardDB / anything under data/scripts; the `.blind.json` carries mana cost, type line, oracle text, rulings and the DSL cheat sheet. If a fact is missing from the blind file, the author reports it in `toolProblems` rather than looking it up.
- **C-2 data shape.** `Verification.scenarios.sampled?: false` in src/cards/scripts.ts AND in the strict zod object in src/cards/schema-core.ts (a `sampled: z.literal(false).optional()`; forgetting the schema fails stage 1 for every promoted file — test it). `WaveBatchResult` (scripts-promote.ts) gains `blindRate?: number; blindSampling?: { oracleId: string; blindSampled: boolean }[]`.

Per card: `unsampled = blindSampling says false && !owner.has(id)`; unsampled with no scenario rows → `v.scenarios = { file: '', passed: 0, failed: 0, names: [], sampled: false }`; an owner card arriving unsampled → NOTE line, `scenarios` untouched. `deriveStatus`: `v.problems` guard first (already there); `unsampled = v.scenarios.sampled === false` satisfies `tested`; unfaithful verdict on an unsampled card → `verified` (never `tested`); enough faithful → `judged`; otherwise `verified` when unsampled, `tested` when sampled.
